# Space Wars

A separate browser strategy game in the Space Explorer universe, focused on fast territorial warfare in a shared galaxy with human and bot commanders.

This repository is in the **architecture review phase**. No gameplay implementation or Supabase project has been created by this audit. Implementation starts only after owner review and approval. The selected battle system is the Web game's Battle Lab V2 top-down combat.

Read [AGENTS.md](AGENTS.md) before working here. Space Explorer reference repositories are read-only, and Space Wars must remain independently deployable with its own backend.
